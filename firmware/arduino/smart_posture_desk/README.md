# Smart Posture Desk Arduino firmware

Arduino Uno R3가 Raspberry Pi의 USB 시리얼 명령을 받아 다음 장치를 제어하는 초기 실험용 펌웨어입니다.

- A4988 + `17HS3401S-T8x8` 리드스크루 스텝모터: 상판 기울기
- L298N + 12 V 미니 리니어 액추에이터: 책상 높이
- 외부 리미트 스위치와 물리 비상정지는 아직 사용하지 않음

## 현재 버전의 제약

이 버전은 모터의 회전 방향과 기본 통신을 확인하기 위한 시제품 코드입니다. 리미트 스위치와 물리 비상정지가 없으므로 상판이나 무거운 하중을 연결한 자동 운전에는 사용하지 않습니다.

1. 첫 시험은 모터와 액추에이터를 책상에서 분리한 무부하 상태로 진행합니다.
2. 스텝모터는 전원이 꺼지면 위치를 잃습니다. 기준 위치에 둔 후 반드시 `SET_ZERO`를 보내야 합니다.
3. `SET_ZERO`는 모터를 움직이지 않고 현재 위치를 0 mm로 기록할 뿐입니다. 자동 원점 복귀는 리미트 스위치를 추가한 뒤 구현합니다.
4. 액추에이터는 위치 피드백이 없어 실제 이동거리를 알 수 없습니다. 명령 하나의 최대 구동시간은 정격 속도 9.5 mm/s로 100 mm 전체 스트로크를 이동하는 이론값을 올림한 10,527 ms입니다.
5. `STOP` 명령과 통신 watchdog은 남아 있지만 물리 비상정지를 대신하지는 못합니다.
6. 액추에이터의 표기 최대 전류가 약 2.1 A라면 L298N 모듈의 여유가 부족합니다. L298N은 짧은 무부하 시험에만 사용하고, 실제 하중 시험 전에는 정격에 여유가 있는 H-브리지 드라이버로 교체합니다.

## 현재 핀 연결

| Arduino Uno | 연결 대상 | 비고 |
|---|---|---|
| D2 | A4988 STEP | |
| D3 | A4988 DIR | 방향이 반대면 `TILT_UP_DIR_LEVEL` 변경 |
| D4 | A4988 ENABLE | LOW 활성 |
| D5 | L298N ENA | L298N의 ENA 점퍼 제거, PWM 출력 |
| D6 | L298N IN1 | 액추에이터 방향 |
| D7 | L298N IN2 | 액추에이터 방향 |
| D8~D12 | 미사용 | 향후 리미트 스위치·비상정지용으로 예약 |

### A4988 전원과 마이크로스텝

- `VMOT`에는 12 V, `VDD`에는 Arduino 5 V를 연결합니다.
- 12 V 전원 음극, Arduino GND, A4988 GND, L298N GND는 공통으로 연결합니다.
- A4988 `RESET`과 `SLEEP`을 서로 연결하고 5 V에 연결합니다.
- 1/8 마이크로스텝: `MS1=5 V`, `MS2=5 V`, `MS3=GND`.
- A4988의 `VMOT-GND` 바로 옆에 `100 uF 이상` 전해 커패시터를 연결합니다.
- A4988 전류 제한은 모터 정격 1.3 A 이하로 설정해야 합니다. 클론 보드의 감지저항 값에 따라 VREF 계산이 달라지므로 저항 표기와 판매처 회로를 확인하지 않은 채 VREF 값을 추측하지 않습니다.
- 모터 전원이 들어온 상태에서 모터선을 꽂거나 빼지 않습니다.

### 전원 연결

- 12 V 5 A 어댑터는 A4988의 `VMOT`와 L298N의 모터 전원에 병렬 분배합니다.
- Arduino는 Raspberry Pi의 USB 또는 별도 안정화 5 V로 공급합니다.
- 12 V를 Arduino의 5 V 핀에 연결하지 않습니다.
- L298N 보드의 5 V 출력과 Arduino 5 V 출력을 서로 연결하지 않습니다.

## 시리얼 명령

115200 baud, 줄바꿈(`\n`)으로 명령을 끝냅니다.

| 명령 | 예시 | 의미 |
|---|---|---|
| `PING` | `PING` | 통신 확인 및 watchdog 갱신 |
| `STATUS` | `STATUS` | 기준점 설정 여부, 계산상 위치, 동작 상태 조회 |
| `STOP` | `STOP` | 두 모터 정지 |
| `SET_ZERO` | `SET_ZERO` | 스텝모터의 현재 위치를 0 mm로 지정 |
| `TILT <mm>` | `TILT 5` | 수동 기준점에서 지정 위치로 이동 |
| `TILT_REL <mm>` | `TILT_REL -2` | 계산상 현재 위치에서 상대 이동 |
| `HEIGHT UP <ms>` | `HEIGHT UP 500` | 지정 시간 동안 액추에이터 올림 |
| `HEIGHT DOWN <ms>` | `HEIGHT DOWN 500` | 지정 시간 동안 액추에이터 내림 |

`HOME` 명령은 리미트 스위치를 추가하기 전까지 `ERR HOME_REQUIRES_LIMIT_SWITCH`를 반환합니다.

동작 중에는 Raspberry Pi가 3초보다 짧은 간격으로 `PING`을 보내야 합니다. 통신이 끊기면 watchdog이 모든 동작을 정지합니다. 두 모터는 동시에 움직이지 않도록 펌웨어에서 막았습니다.

`TILT`의 mm 값은 각도가 아니라 리드스크루 너트의 이동 거리입니다. 현재 소프트웨어 최대값은 100 mm입니다. 실제 상판 각도와 매핑하려면 경첩 중심과 연결점의 치수로 계산하거나 여러 위치에서 각도를 실측해 보정표를 만들어야 합니다.

`ACTUATOR_MAX_RUN_MS`는 `100 mm / 9.5 mm/s = 10.5263초`를 기준으로 `10,527 ms`로 설정했습니다. 이는 정격 속도 기준의 이론값이며, 현재 `ACTUATOR_TEST_PWM = 180` 설정과 L298N의 전압 강하, 실제 하중 때문에 100 mm 이동에 더 오래 걸릴 수 있습니다. 위치 피드백과 외부 리미트 스위치가 없으므로 액추에이터 끝에 도달한 뒤 계속 힘을 가하지 않도록 반드시 눈으로 보면서 시험합니다.

## 첫 무부하 테스트 순서

1. 12 V 모터 전원을 빼고 Arduino만 USB로 연결합니다.
2. Arduino IDE의 시리얼 모니터를 `115200 baud`, 줄바꿈으로 설정합니다.
3. `STATUS`를 보내 `TILT_ZERO_SET=0`인지 확인합니다.
4. 모터와 기구를 분리한 상태에서 A4988 전류 제한을 설정합니다.
5. 리드스크루 너트를 양 끝에서 충분히 떨어진 위치에 둔 뒤 12 V 전원을 연결합니다.
6. `SET_ZERO`를 보내고 `TILT 2`를 실행합니다. 너트가 원하는 상승 방향의 반대로 움직이면 즉시 `STOP`하고 `TILT_UP_DIR_LEVEL`의 `HIGH`를 `LOW`로 바꿉니다.
7. `TILT 0`, `TILT 2`, `TILT 5`처럼 짧은 범위에서 반복 시험합니다.
8. 액추에이터는 상판과 분리한 채 `HEIGHT UP 200`, `HEIGHT DOWN 200`부터 시험합니다. 방향이 반대라면 L298N 출력선 두 개를 서로 바꾸거나 코드의 IN1/IN2 출력을 바꿉니다.
9. 모터가 움직이는 동안 `PING`을 주기적으로 보내고, `STOP`과 통신 단절 정지도 시험합니다.

## 실측 후 바꿀 값

스케치 상단의 다음 값을 실제 기구에 맞게 조정합니다.

- `TILT_UP_DIR_LEVEL`: 실제 상승 방향
- `TILT_MAX_TRAVEL_MM`: 수동 0점부터 허용할 안전 이동 거리
- `TILT_SPEED_MM_PER_SEC`: 탈조가 없는 속도
- `ACTUATOR_MAX_RUN_MS`: 한 번에 허용할 최대 구동 시간
- `ACTUATOR_TEST_PWM`: 드라이버와 액추에이터의 발열을 확인하며 조정

리미트 스위치와 비상정지를 추가할 때는 D8~D12를 입력으로 사용하고, 자동 `HOME`, 기울기 상·하단 정지, 높이 상·하단 정지, NC 비상정지 로직을 다시 활성화합니다.
