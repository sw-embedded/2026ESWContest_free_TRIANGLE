# Smart Posture Desk Arduino firmware

Arduino Uno R3가 Raspberry Pi의 USB 시리얼 명령을 받아 책상 기울기와 높이를 제어하는 펌웨어입니다. 기존 A4988/L298N 제어 코드의 비차단 상태 머신을 유지하면서 팀원 코드의 리미트 스위치, 전류 과부하 감지, 완만한 가속·감속 아이디어를 통합했습니다.

> 이 펌웨어는 실제 기구의 안전 인증을 대신하지 않습니다. 처음에는 모터를 책상에서 분리한 무부하 상태로 시험하고, 물리 비상정지와 전원 차단 장치를 별도로 사용하세요.

## 핀 연결

| Arduino Uno | 연결 대상 | 동작 |
|---|---|---|
| D2 | A4988 STEP | 기울기 스텝 펄스 |
| D3 | A4988 DIR | 기울기 방향 |
| D4 | A4988 ENABLE | LOW 활성 |
| D5 | L298N ENA | PWM, ENA 점퍼 제거 |
| D6/D7 | L298N IN1/IN2 | 높이 액추에이터 방향 |
| D8/D9 | 기울기 하단/상단 리미트 | `INPUT_PULLUP`, 눌리면 GND |
| D10/D11 | 높이 상단/하단 리미트 | `INPUT_PULLUP`, 눌리면 GND |
| D12 | 비상정지 입력 | `INPUT_PULLUP`, 동작 시 GND |
| A0 | 전류 센서 아날로그 출력 | 과부하 감지 |

A4988은 `MS1=5 V`, `MS2=5 V`, `MS3=GND`인 1/8 마이크로스텝을 가정합니다. 12 V 전원 음극, Arduino GND, A4988 GND, L298N GND는 공통으로 연결합니다. A4988 VMOT 근처에는 100 uF 이상의 전해 커패시터를 연결하고 모터 정격에 맞춰 전류 제한을 먼저 설정해야 합니다.

L298N은 전압 강하와 전류 여유가 작습니다. 실제 하중에서 액추에이터 전류가 드라이버 정격에 가까우면 여유 있는 H-브리지 드라이버로 교체하세요.

## 통신 규격

9600 baud를 사용합니다. `N/W/C/H` 상태 프로토콜은 대소문자를 구분하지 않습니다. 줄바꿈으로 끝나는 명령을 권장하지만, 줄바꿈 없는 한 글자 명령도 30 ms의 입력 유휴 시간 후 처리합니다.

| 명령 | 동작 |
|---|---|
| `N` (Normal) | 정상 자세 상태, 모든 모터 즉시 정지 |
| `W` (Warning) | 경고 상태, 모터를 구동하지 않고 기존 동작 정지 |
| `C` (Critical) | `AUTO_TILT_TARGET_MM` 위치로 자동 기울기 이동 |
| `H` (Heartbeat) | watchdog 갱신 및 `PONG` 응답 |
| `STOP` | 모든 모터 즉시 정지 |
| `PING`, `KEEPALIVE` | watchdog 갱신 및 `PONG` 응답 |
| `STATUS` | 위치, 상태, 전류값, 리미트와 비상정지 상태 출력 |
| `HOME` | 기울기 하단 리미트까지 이동해 0점 설정 |
| `SET_ZERO` | 현재 기울기 위치를 수동으로 0 mm 설정 |
| `TILT <mm>` | 0점 기준 절대 위치로 이동 |
| `TILT_REL <mm>` | 현재 계산 위치 기준 상대 이동 |
| `HEIGHT UP <ms>` | 지정 시간 동안 높이 올림 |
| `HEIGHT DOWN <ms>` | 지정 시간 동안 높이 내림 |

상태 프로토콜은 `N`(Normal), `W`(Warning), `C`(Critical), `H`(Heartbeat)로 통일했습니다. `C`만 자동 기울기 보정을 시작하며, `N`과 `W`는 안전을 위해 진행 중인 모터 동작도 정지합니다. `A/S/T/B`는 더 이상 제어 명령으로 사용하지 않습니다.

동작 중에는 3초보다 짧은 간격으로 `H`를 보내야 합니다. `PING`과 `KEEPALIVE`도 진단 호환용으로 사용할 수 있습니다. 자동 보정 5 mm는 기본 설정에서 약 1.25초 안에 끝나지만, 더 긴 수동 명령과 `HOME`에는 주기적인 heartbeat가 필요합니다. 통신이 끊기거나 비상정지가 눌리면 두 모터를 즉시 정지하며, 기울기와 높이 모터는 동시에 움직일 수 없습니다.

## 안전 동작

- 기울기 상·하단과 높이 상·하단 리미트를 이동 방향별로 확인합니다.
- 부팅할 때 기울기 하단 리미트만 눌려 있으면 그 위치를 자동으로 0점으로 인식합니다.
- 한 축의 상·하단 리미트가 동시에 눌린 비정상 배선 상태에서는 동작하지 않습니다.
- 높이 모터는 비차단 PWM 램프로 가속하고, 정상 시간 종료 시 감속합니다. 정지·리미트·비상정지는 감속을 기다리지 않고 즉시 출력을 끕니다.
- A0 전류값이 `CURRENT_THRESHOLD`를 10 ms 간격으로 연속 3회 넘으면 즉시 정지합니다.
- 상승 중 과부하라면 100 ms 동안 출력을 끈 뒤, 하단 리미트를 다시 확인하고 낮은 PWM으로 300 ms만 역동작합니다. 하강 중 과부하는 역동작하지 않고 정지만 합니다.
- 기울기 이동 범위, 높이 명령 최대 시간, 30초 기울기 타임아웃을 함께 적용합니다.

## 최초 점검 순서

1. 12 V 모터 전원을 분리하고 USB 시리얼만 연결합니다.
2. 각 리미트와 비상정지를 하나씩 눌러 `STATUS`의 `LIMITS`/`ESTOP` 값이 바뀌는지 확인합니다. `LIMITS` 순서는 기울기 하단·상단, 높이 하단·상단입니다.
3. 전류 센서의 무부하·정상 하중·구속 직전 값을 `STATUS`로 측정해 `CURRENT_THRESHOLD`를 보정합니다.
4. 모터를 기구에서 분리하고 A4988 전류 제한을 설정한 뒤 `HOME`, `TILT 2`, `TILT 0` 순서로 방향과 리미트를 확인합니다.
5. 방향이 반대면 `TILT_UP_DIR_LEVEL`을 바꿉니다.
6. 액추에이터를 무부하로 두고 `HEIGHT UP 200`, `HEIGHT DOWN 200`부터 시험합니다.
7. 이동 중 `STOP`, 비상정지, 각 리미트, 통신 단절, 과부하 정지를 각각 시험합니다.

## 실측 후 조정할 값

- `TILT_UP_DIR_LEVEL`
- `TILT_MAX_TRAVEL_MM`
- `TILT_SPEED_MM_PER_SEC`
- `AUTO_TILT_TARGET_MM`
- `ACTUATOR_MAX_RUN_MS`
- `ACTUATOR_RUN_PWM`
- `CURRENT_THRESHOLD`
- `SAFETY_REVERSE_PAUSE_MS`
- `SAFETY_REVERSE_MS`

센서를 연결하지 않은 무부하 벤치 테스트에서만 `LIMIT_SWITCHES_ENABLED`, `EMERGENCY_STOP_ENABLED`, `CURRENT_SENSOR_ENABLED`를 `false`로 바꾸세요. 실제 책상에 연결할 때는 세 안전 기능을 다시 활성화해야 합니다.
