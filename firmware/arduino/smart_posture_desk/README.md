# Smart Posture Desk Arduino firmware

Arduino Uno R3가 Raspberry Pi의 USB 시리얼 명령을 받아 책상 기울기와 높이를 제어하는 펌웨어입니다. A4988/L298N 비차단 상태 머신과 전류 과부하 감지, 완만한 가속·감속, 단일 비상정지 스위치를 사용합니다.

> 이 펌웨어는 실제 기구의 안전 인증을 대신하지 않습니다. 처음에는 모터를 책상에서 분리한 무부하 상태로 시험하고, 물리 비상정지와 전원 차단 장치를 별도로 사용하세요.

## 핀 연결

| Arduino Uno | 연결 대상 | 동작 |
|---|---|---|
| D2 | A4988 DIR | 기울기 방향 |
| D3 | A4988 STEP | 기울기 스텝 펄스 |
| D4~D6 | 사용하지 않음 | A4988 ENABLE은 LOW 활성 상태 유지, L298N ENA 점퍼 장착 |
| D7/D8 | L298N IN1/IN2 | 높이 액추에이터 방향 |
| D9~D11 | 사용하지 않음 | 리미트 스위치 비활성화 |
| D12 | 비상정지 입력 | `INPUT_PULLUP`, 동작 시 GND |
| A0 | 전류 센서 아날로그 출력 | 과부하 감지 |

A4988은 `MS1/MS2/MS3`을 연결하지 않은 Full-Step을 가정합니다. 12 V 전원 음극, Arduino GND, A4988 GND, L298N GND는 공통으로 연결합니다. A4988 VMOT 근처에는 100 uF 이상의 전해 커패시터를 연결하고 모터 정격에 맞춰 전류 제한을 먼저 설정해야 합니다.

L298N은 전압 강하와 전류 여유가 작습니다. 실제 하중에서 액추에이터 전류가 드라이버 정격에 가까우면 여유 있는 H-브리지 드라이버로 교체하세요.

## 통신 규격

9600 baud를 사용합니다. `N/W/C/H/R` 상태 프로토콜은 대소문자를 구분하지 않습니다. 줄바꿈으로 끝나는 명령을 권장하지만, 줄바꿈 없는 한 글자 명령도 30 ms의 입력 유휴 시간 후 처리합니다.

| 명령 | 동작 |
|---|---|
| `N` (Normal) | 정상 자세 상태, 모든 모터 즉시 정지 |
| `W` (Warning) | 경고 상태, 모터를 구동하지 않고 기존 동작 정지 |
| `C TURTLE_NECK` (Critical) | 거북목 교정: 시작 위치에서 `AUTO_TILT_DELTA_MM`만큼 기울기 이동 |
| `C BENT_BACK` (Critical) | 굽은 허리 교정: `AUTO_HEIGHT_ADJUST_MS` 동안 높이 올림 |
| `H` (Heartbeat) | watchdog 갱신 및 `PONG` 응답 |
| `R` (Restore) | 적용된 교정 종류에 따라 기울기 또는 높이를 기준 위치로 복귀 |
| `STOP` | 모든 모터 즉시 정지 |
| `PING`, `KEEPALIVE` | watchdog 갱신 및 `PONG` 응답 |
| `STATUS` | 위치, 교정 상태, 전류값과 비상정지 상태 출력 |
| `HOME` | 리미트를 사용하지 않으므로 현재 구성에서는 거부됨 |
| `SET_ZERO` | 현재 기울기 위치를 수동으로 0 mm 설정 |
| `TILT <mm>` | 0점 기준 절대 위치로 이동 |
| `TILT_REL <mm>` | 현재 계산 위치 기준 상대 이동 |
| `HEIGHT UP <ms>` | 지정 시간 동안 높이 올림 |
| `HEIGHT DOWN <ms>` | 지정 시간 동안 높이 내림 |

상태 프로토콜은 `N`(Normal), `W`(Warning), `C <posture>`(Critical), `H`(Heartbeat)와 `R`(Restore)을 사용합니다. 교정이 한 번 적용되면 `R`로 원위치 복귀가 끝날 때까지 다른 교정·수동 이동 명령을 거부합니다. `N`과 `W`는 진행 중인 동작을 정지시키지만 교정 잠금은 해제하지 않습니다. `A/S/T/B` 한 글자는 더 이상 제어 명령으로 사용하지 않습니다.

명령 watchdog은 5분(`300000 ms`)이며, Raspberry Pi는 영상 처리와 분리된 시리얼 작업 스레드에서 기본 2초 간격으로 `H`를 보냅니다. `PING`과 `KEEPALIVE`도 진단 호환용으로 사용할 수 있습니다. 기울기 교정 전 4초 대기는 비차단 상태로 처리되어 대기 중에도 시리얼 명령과 안전 입력을 계속 확인합니다. 5분 동안 유효한 명령이 없거나 비상정지가 눌리면 두 모터를 즉시 정지하며, 기울기와 높이 모터는 동시에 움직일 수 없습니다.

## 안전 동작

- 부팅 순간의 기울기를 소프트웨어 0점으로 설정합니다.
- 기울기 위치가 소프트웨어 0 mm가 아니면 높이 축을 구동하지 않습니다.
- 거북목/굽은 허리 중 하나의 교정이 적용되면 원위치 복귀 전까지 다른 자세가 감지되어도 추가로 움직이지 않습니다.
- 거북목 교정 시작 위치의 스텝 수를 기억하고 복귀할 때 같은 위치로 되돌립니다.
- 높이 모터는 비차단 PWM 램프로 가속하고, 정상 시간 종료 시 감속합니다. 정지·비상정지는 감속을 기다리지 않고 즉시 출력을 끕니다.
- A0 전류값이 `CURRENT_THRESHOLD`를 10 ms 간격으로 연속 3회 넘으면 즉시 정지합니다.
- 상승 중 과부하라면 100 ms 동안 출력을 끈 뒤 낮은 PWM으로 300 ms만 역동작합니다. 하강 중 과부하는 역동작하지 않고 정지만 합니다.
- 기울기 이동 범위, 높이 명령 최대 시간, 30초 기울기 타임아웃을 함께 적용합니다.

## 최초 점검 순서

1. 12 V 모터 전원을 분리하고 USB 시리얼만 연결합니다.
2. D12 비상정지를 눌러 `STATUS`의 `ESTOP` 값이 1로 바뀌는지 확인합니다.
3. 전류 센서의 무부하·정상 하중·구속 직전 값을 `STATUS`로 측정해 `CURRENT_THRESHOLD`를 보정합니다.
4. 상판을 기준 시작 위치에 둔 채 전원을 켜고, 모터를 기구에서 분리한 상태에서 `TILT 2`, `TILT 0` 순서로 방향과 소프트웨어 복귀를 확인합니다.
5. 방향이 반대면 `TILT_UP_DIR_LEVEL`을 바꿉니다.
6. 액추에이터를 무부하로 두고 `HEIGHT UP 200`, `HEIGHT DOWN 200`부터 시험합니다.
7. 이동 중 `STOP`, 비상정지, 통신 단절, 과부하 정지를 각각 시험합니다.

## 실측 후 조정할 값

- `TILT_UP_DIR_LEVEL`
- `TILT_MAX_TRAVEL_MM`
- `TILT_SPEED_MM_PER_SEC`
- `AUTO_TILT_DELTA_MM`
- `ACTUATOR_MAX_RUN_MS`
- `ACTUATOR_RUN_PWM`
- `CURRENT_THRESHOLD`
- `SAFETY_REVERSE_PAUSE_MS`
- `SAFETY_REVERSE_MS`

현재 구성은 `LIMIT_SWITCHES_ENABLED=false`, `EMERGENCY_STOP_ENABLED=true`입니다. D12 스위치는 `INPUT_PULLUP`으로 설정되며 누르면 GND에 연결되도록 배선합니다. 전류 센서를 사용하지 않을 경우에만 `CURRENT_SENSOR_ENABLED=false`로 변경하세요.
