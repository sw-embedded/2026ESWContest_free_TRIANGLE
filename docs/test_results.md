# 🧪 시스템 성능 및 동작 테스트 결과

## 1. 자세 인식 정밀도 및 응답 속도
- **MoveNet TFLite 추론 속도**: 평균 ~30~40 ms (Raspberry Pi 기준)
- **자세 전환 감지 타임**: 약 0.1초 이내 상태 전환 및 아두이노 명령 전송 확인

## 2. 하드웨어 구동 및 안전 제어 검증
- **Watchdog 설정**: 현재 시리얼 신호 중단 허용 시간을 5분으로 변경 (`COMMAND_WATCHDOG_MS=300000`), 실제 장비에서 시간 경과 정지 재검증 필요
- **손끼임 과부하 테스트**: 전류 센서 임계값 초과 시 모터 즉시 정지 및 안전 역동작(0.3초 하강) 검증 완료
