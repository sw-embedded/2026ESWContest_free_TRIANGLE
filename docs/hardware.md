# 하드웨어 구성과 안전 확인

## 현재 Arduino 펌웨어 핀 맵

아래 표는 실물 배선을 확인한 결과가 아니라
`arduino/desk_controller/desk_controller.ino`의 현재 상수입니다.

| 핀 | 코드상 연결 | 코드 상태 |
|---|---|---|
| D2 | A4988 DIR | 출력 |
| D3 | A4988 STEP | 출력 |
| D4 | 미사용 | A4988 ENABLE LOW 고정 |
| D5 | 미사용 | L298N ENA 점퍼 연결 |
| D6 | 미사용 | - |
| D7 | L298N IN1 | 출력 |
| D8 | L298N IN2 | 출력 |
| D9-D11 | 미사용 | - |
| D12 | Emergency Stop | `INPUT_PULLUP`, Active-LOW |
| A0 | Current Sensor | 펌웨어상 활성 |

D12 비상정지 버튼은 평소 열림(NO) 접점 기준으로 D12와 GND 사이에 연결합니다.
버튼을 누르면 `INPUT_PULLUP` 입력이 LOW가 되고 모든 모터 구동을 정지합니다.

## 코드 구현 안전 기능

| 기능 | 코드 구현 | 실물 검증 |
|---|---|---|
| 명령 Watchdog | 3000 ms(3초) | 확인 필요 |
| 기울기 motion timeout | 30000 ms | 확인 필요 |
| 높이 최대 구동 시간 | 10527 ms | 확인 필요 |
| 다축 동시 구동 방지 | 구현 | 확인 필요 |
| D12 비상정지 | 구현, Active-LOW | 장착/동작 확인 필요 |
| A0 과전류 감지 | 10 ms 간격 3회, threshold 500 | 센서 장착/보정 확인 필요 |
| 과전류 안전 역동작 | 상승 중 100 ms 정지 후 300 ms 하강 | 확인 필요 |

Raspberry Pi의 heartbeat 기본 주기는 2초이고 Arduino Watchdog은 3초입니다.
실제 부하와 통신 지연 조건에서 오탐 정지 없이 동작하는지 확인해야 합니다.
자동 높이 동작에는 별도 시간 제한이, 기울기 동작에는 목표 위치와 30초 timeout이
함께 적용됩니다.

## 실물 시험 전 주의

1. 12 V 모터 전원을 분리한 상태에서 펌웨어 업로드와 시리얼 응답을 확인합니다.
2. 실물 배선과 코드 핀표를 한 핀씩 대조합니다.
3. D12 비상정지를 GND에 연결해 `STATUS`의 `ESTOP=1`과 전체 구동 정지를 확인합니다.
4. 모터를 기구에서 분리한 무부하 상태로 방향과 `STOP`을 먼저 확인합니다.
5. E-stop, 통신 단절, 과전류는 각각 별도 시험하고 결과를 기록합니다.
6. 현재 `CURRENT_THRESHOLD=500`은 실측 보정 전 값으로 취급합니다.

실제 하드웨어 시험은 이 저장소 점검에서 수행하지 않았습니다.
